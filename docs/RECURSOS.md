# Recursos visuales

El logo y los iconos de `src/public/assets/` provienen del ZIP del frontend original proporcionado por los autores. Se conserva el logo en el inicio; algunos iconos originales quedan disponibles como parte de los recursos integrados.

Las fotografías se descargaron para que el catálogo de demostración no dependa de un servicio externo al ejecutar la aplicación. Sus fuentes son páginas de Unsplash, bajo su [licencia](https://unsplash.com/license):

Las marcas y fotografías son ilustrativas. No hay afiliación comercial con sus titulares. `fallback.svg` es un gráfico sencillo creado para esta integración.

Las capturas en `docs/capturas/` muestran la aplicación real con esos productos de demostración. Se pueden regenerar con `npm run screenshots`.
